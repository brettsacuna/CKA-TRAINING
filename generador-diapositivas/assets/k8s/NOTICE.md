# Iconos de Kubernetes

Los archivos `*.png` de esta carpeta proceden del **Kubernetes Icons Set**:

- Fuente: https://github.com/kubernetes/community/tree/main/icons
- Logotipo (`kubernetes.png`): https://github.com/cncf/artwork (proyecto Kubernetes)
- Licencia: **Apache-2.0** o **CC-BY-4.0**, a elección del usuario.
- © The Kubernetes Authors / Cloud Native Computing Foundation.

Se usan sin modificar (solo se reescalan) como iconos de tema en las
presentaciones del curso. La atribución se cumple con este archivo.
